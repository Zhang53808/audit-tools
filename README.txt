📸 拍凭重命名工具包

三个脚本，放在桌面「拍凭重命名」文件夹里。

====================================
场景A：已经整理好的文件，直接重命名
====================================
用：rename_vouchers.py
终端：cd ~/Desktop/拍凭重命名 && python3 rename_vouchers.py

====================================
场景B：原始扫描件（拍手指版）
====================================
第一步：process_raw_scans.py
  跑完出分组CSV，打开填凭证号

第二步：rename_from_csv.py
  跑完自动重命名

====================================
用法提示
====================================
cd ~/Desktop/拍凭重命名
python3 脚本名.py

然后按提示拖文件夹进去就行
