# 审计自动化工具包

这个目录是一组面向年审现场工作的 Python 小工具，主要用于减少重复性的 Excel 清洗、固定资产折旧测算、凭证扫描件整理和批量重命名工作。

## 运行环境

需要安装 Python 3.9 或以上版本。

依赖：

```bash
pip install openpyxl
```

在 Windows PowerShell 中运行：

```powershell
cd C:\Users\exexex6661\Desktop\audit-tools
python 脚本名.py
```

在 macOS 终端中运行：

```bash
cd ~/Desktop/audit-tools
python3 脚本名.py
```

脚本启动后通常会提示“把文件或文件夹拖进终端”，按提示拖入后回车即可。

## 脚本一览

| 脚本 | 用途 | 主要输出 |
| --- | --- | --- |
| `depreciation_check.py` | 固定资产折旧年审测算 | `原文件名_折旧年审结果.xlsx` |
| `clean_vouchers.py` | 清洗凭证/明细类 Excel | `原文件名_已清洗.xlsx` |
| `rename_vouchers.py` | 对已经整理好的凭证 PDF 批量重命名 | 重命名后的 PDF、`凭证清单.csv`、`原文件备份/` |
| `process_raw_scans.py` | 对原始扫描件按分隔标记分组 | `凭证分组清单.csv` |
| `rename_from_csv.py` | 根据填好的分组清单重命名原始扫描件 | 重命名后的图片/PDF、`原文件备份/` |

## 固定资产折旧测算

运行：

```bash
python depreciation_check.py
```

适用场景：客户提供固定资产明细表，需要审计人员重新测算本年折旧，并与客户账面本年折旧额对比。

主要流程：

1. 读取客户 Excel 的第一个 sheet。
2. 自动识别表头和字段位置。
3. 首次使用时让你确认数据起始行、是否按月分组、审计年度、折旧方法等。
4. 可将配置保存到 `客户配置/客户文件名.json`，下次同名文件可直接复用。
5. 重新计算本年应提折旧。
6. 输出含“折旧测算”和“差异汇总”两个 sheet 的 Excel。

支持的折旧计算方式：

- 直线法：`(原值 - 残值) / 使用寿命(月) * 应提月数`
- 月折旧率法：`原值 * 月折旧率 / 100 * 应提月数`

应提月数规则：

- 以前年度入账：默认全年 12 个月。
- 当年入账：从入账次月开始计提，例如 3 月入账则提 9 个月。
- 年初已提足：本年计提 0。
- 有处置且能识别处置月份：计提到处置月份。

注意：

- 使用寿命字段如果小于等于 50，脚本会按“年”理解并自动乘以 12；大于 50 按“月”理解。
- 客户表头差异较大时，自动识别可能不完整，脚本会提示手动输入列号。列号从 0 开始。
- 当前只处理第一个 sheet。

## 凭证 Excel 清洗

运行：

```bash
python clean_vouchers.py
```

适用场景：客户导出的凭证明细格式比较脏，需要统一月份、金额，并删除空行/合计行。

脚本会：

- 自动查找表头行。
- 跳过空行、合计行、序号为空的行。
- 将 `2025年3月`、`03月`、`3` 等统一成 `3月`。
- 清洗金额中的 `¥`、`￥`、逗号、空格和括号负数。
- 输出 `原文件名_已清洗.xlsx`。

## 已整理凭证 PDF 重命名

运行：

```bash
python rename_vouchers.py
```

适用场景：PDF 文件名里已经包含月份、日期、凭证字、凭证号等信息，只需要统一命名。

脚本会尝试识别这些格式：

- `6月16日 记357 摘要.pdf`
- `6月16日357 摘要.pdf`
- `6-357 摘要.pdf`
- `6月357 摘要.pdf`

输出文件名格式：

```text
客户简称 + 年份 + 月月 + 日日 + 凭证字 + 凭证号.pdf
```

例如：

```text
A公司20250616记357.pdf
```

安全措施：

- 重命名前会生成 `凭证清单.csv` 供检查。
- 只有输入 `y` 才会真正重命名。
- 原始 PDF 会复制到 `原文件备份/`。
- 如果目标文件名已存在，会自动追加 `_2`、`_3` 等后缀。

## 原始扫描件分组和重命名

这是一套两步流程，适用于扫描件还没有规范命名、需要先按每笔凭证分组的情况。

第一步，生成分组清单：

```bash
python process_raw_scans.py
```

脚本支持图片和 PDF：

- `.jpg`
- `.jpeg`
- `.png`
- `.heic`
- `.pdf`

分隔文件识别方式：

- 文件名包含关键字，例如 `finger`、`sep`。
- 文件大小小于指定 KB。
- 不自动识别，全部按连续文件处理。

输出：

```text
凭证分组清单.csv
```

打开 CSV，填写这些列：

- `凭证字`
- `凭证号`
- `日期(日)`
- `科目/摘要`

第二步，根据清单重命名：

```bash
python rename_from_csv.py
```

脚本会按清单中的分组数量依次匹配扫描件，生成统一文件名，并把原始文件备份到 `原文件备份/`。

## 文件和目录说明

运行过程中可能生成：

- `客户配置/`：保存折旧测算的字段匹配配置，已加入 `.gitignore`。
- `原文件备份/`：重命名前自动备份原始文件。
- `凭证清单.csv`：`rename_vouchers.py` 生成的解析清单。
- `凭证分组清单.csv`：`process_raw_scans.py` 生成的分组清单。
- `*_已清洗.xlsx`：清洗结果。
- `*_折旧年审结果.xlsx`：折旧测算结果。

## 使用建议

1. 批量重命名前，先在少量测试文件夹里跑一遍。
2. 不要直接在客户唯一原件目录里测试，先复制一份工作目录。
3. 折旧测算首次保存配置后，如果客户表结构变了，需要删除对应 `客户配置/*.json` 后重新识别。
4. Excel 文件如果打开着，脚本可能无法覆盖输出文件，请先关闭 Excel 再运行。
